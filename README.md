# The Blog - A Web Personal Blog

This is a clean, modern personal blog website based on a Figma design. The website features a responsive layout, light/dark mode toggle, and a beautiful, consistent design.

## Features

- **Responsive Design**: Adapts to different screen sizes
- **Light/Dark Mode**: Toggle between light and dark color schemes
- **Modern UI**: Clean, minimalist design with attention to typography and spacing
- **Blog Post Cards**: Visually appealing presentation of blog content
- **Category Badges**: Color-coded badges for different post categories
- **Pagination**: Intuitive pagination system

## Technology Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started

1. Clone this repository or download the files
2. Open `index.html` in your web browser

## Customization

- **Content**: Edit the HTML to update blog post titles, descriptions, and author information
- **Colors**: Modify the CSS variables in the `:root` selector to change the color scheme
- **Images**: Replace the images in the `images` folder with your own images
